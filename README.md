# MiniCRM PWA v0.15

Subir estos 3 archivos a la raíz del repositorio de GitHub Pages:

- index.html
- manifest.webmanifest
- sw.js

Reemplazar el index.html anterior.

La PWA usa Supabase como fuente de datos. El Service Worker NO cachea tráfico hacia supabase.co.

## iPhone / iPad
Abrir la URL de GitHub Pages en Safari → Compartir → Agregar a pantalla de inicio.

## PC
En navegadores compatibles puede aparecer la opción Instalar aplicación en la barra de direcciones o menú.
